Waiting for a palette…

Palette Voronoi Visualiser — paste a colour list in any common notation (optionally named) to get deterministic SVG maps: same input ⇒ identical SVG bytes. Everything is inlined in this single file; it works offline, straight from file://, and the address bar always holds a share link of the current state. Project: github.com/myfonj/voronoi-palette · public version: myfonj.github.io/utils/voronoi-palette.

Grid order
Ergonomics α

Rank-blend strength of the seed layout: 0 = faithful positions, 1 = fully equalised. Even at 0 the picker and mosaic still run Lloyd’s relaxation — only the strict map is untouched geometry.

Hue seam shift

Hue is circular but the X axis is linear, so a seam must land somewhere. Auto-seam bins the hues (36 bins), weights each bin by mean chroma, and hides the seam in the lowest-weighted bin.

Neutral threshold

Colours with chroma ≤ t × the palette’s maximum chroma count as neutral and form the grey column at the left edge. 0 = only exact greys (ok_C = 0). The strict map always uses 0.

Y axis — vertical order

HSL lightness and mean RGB are deliberately naive (sRGB-gamma arithmetic) — useful for showing why the perceptual spaces exist. APCA variants are honest but cram dark (resp. light) colours together: contrast utility, not visual distinctiveness.

X axis — hue wheel

Neutrals always sit on a fake-hue diagonal in a quiet corridor of the chosen wheel (OKLCH ≈ 192–228°, HSL ≈ 180–216°) when they mix into the field (mosaic).
